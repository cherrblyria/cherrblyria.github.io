# Project Brief

## Overview

`cherrblyria.github.io` is a personal landing page / portfolio site for **Nutty** (cherrblyria), a high school student in Thailand learning web development. It is served via GitHub Pages as a user site (repo name = username.github.io).

## Core Requirements

- Single-page static site presenting: about, projects, languages/tech, and contact links.
- No build step, no frameworks — plain HTML/CSS/JS served directly by GitHub Pages.
- JavaScript required for the experience (noscript fallback message is provided).
- Visually playful, personalized design: parallax background, Catppuccin (latte) color theme, Google Fonts (Rubik + Noto Sans Thai Looped), Font Awesome icons.
- Dynamic age display computed from a hardcoded birth date in `script.js`.
- Background artwork must be credited (link to the Pixiv source, rendered as `.background-source`).

## Goals

- A cozy, expressive personal homepage that reflects Nutty's interests (Linux, NixOS, Python, web dev).
- Keep the codebase small and hackable so it can be iterated on while learning web development.

## Scope

- In scope: index page styling, animations/interactions, content updates (projects, links), assets.
- Out of scope: backend, build tooling, frameworks, multi-page routing.
